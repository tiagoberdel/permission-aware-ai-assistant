# Plan de capacitación 2027

Se dictará un curso de manejo defensivo en febrero para todos los choferes, y un taller de liderazgo para jefes de área en abril. El presupuesto de capacitación es de $U 1,2 millones. Las inscripciones se gestionan con RR.HH. hasta 20 días antes de cada actividad.
