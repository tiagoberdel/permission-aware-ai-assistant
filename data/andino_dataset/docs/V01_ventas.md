# Manual de ventas

El ciclo de venta tiene cinco etapas: prospección, relevamiento, propuesta, negociación y cierre. El ciclo de venta promedio es de 38 días para clientes nuevos. Toda propuesta debe incluir el plan de rutas, la flota asignada y los tiempos de entrega comprometidos. Las propuestas se registran en el CRM el mismo día de su envío.
